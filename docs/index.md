# Neural Networks from Scratch

Welcome to **Neural Networks from Scratch**!

This project is an open-source, textbook-style journey that demystifies deep learning by building everything from first principles.

## Why this project?
- **Intuition First**: Every mathematical concept is motivated visually and conceptually before formalization.
- **Runnable & Concrete**: Every formula has an accompanying Python/NumPy implementation.
- **Strict Verification**: Analytical gradients are verified against finite-difference numerical approximations and PyTorch autograd.
- **Laptop-Friendly**: Built to run smoothly on Apple Silicon (`mps`) and standard CPUs.
